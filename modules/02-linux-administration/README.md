# Module 2 — Linux Administration (5 videos)

**Goal:** manage a real Linux system — users, permissions, processes, services, logs, and packages. This is where the viewer starts to feel like an admin, not just a user.

| # | Video | Covers |
|---|---|---|
| 05 | [Users & Groups](05-users-and-groups/plan.md) | `sudo`, `useradd`, `passwd`, `groups`, `id` |
| 06 | [Linux Permissions](06-linux-permissions/plan.md) | `chmod`, `chown`, `chgrp`, SUID, SGID, sticky bit |
| 07 | [Process Management](07-process-management/plan.md) | `ps`, `top`, `htop`, `kill`, `jobs`, `bg`, `fg` |
| 08 | [Services & Logs](08-services-and-logs/plan.md) | `systemctl`, `journalctl`, `service`, log files |
| 09 | [Package Management](09-package-management/plan.md) | `apt`, `dpkg`, `yum`, `dnf` |

**Module outcome:** the viewer can administer a running server — control who can do what, keep services alive, and diagnose from logs.
