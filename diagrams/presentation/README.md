# 🎬 Presentation versions

The same module maps, with **big empty space between sections** — made for recording videos:

1. Open a map (`.png`, or the `.excalidraw` at [excalidraw.com](https://excalidraw.com)).
2. Zoom in until one container fills the screen.
3. Scroll down — the next container slides in like a new slide.

For reading on GitHub, use the compact versions one folder up in [`diagrams/`](../).

Both sets are generated by [`../generate.py`](../generate.py).
